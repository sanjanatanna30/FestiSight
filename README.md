# FestiSight – Diwali Sales Analysis & Visualization

## Project Overview

**FestiSight** is a data analysis and visualization project based on Diwali sales data. The project uses **Python** and popular data analysis libraries to explore customer purchasing behavior, sales performance, product categories, demographics, occupations, and regional trends.

The goal of this project is to transform **raw sales data into meaningful business insights to understand customer preferences, high-performing segments, and sales trends.** 

---

## Objectives

* Perform **Exploratory Data Analysis (EDA)** on Diwali sales data.
* Clean and preprocess the raw dataset.
* Analyze customer demographics such as **gender and age group**.
* Identify **top-performing states** based on sales.
* Analyze customer purchasing behavior based on **occupation**.
* Identify popular **product categories and products**.
* Create meaningful visualizations to understand sales patterns.
* Generate actionable insights from the analyzed data.
